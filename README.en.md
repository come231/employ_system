# employ_system

#### Description
JavaWeb项目，后端基于ssm框架，前端基于jsp、Bootstrap、Chart.js，数据库基于Mysql，开发工具为：IDEA；
主要功能：前后台分离；
前台实现考勤打卡、当日考勤数据统计、以及请假、补卡的申请与审批（审批是部门主管功能）；
后台实现考勤数据统计、员工管理、部门管理、考勤记录、请假审批与查看、补卡审批与查看、公司考勤分析、部门分析、考勤规则、日志记录
